🧠 Algorithm Visualizer
An interactive web-based Algorithm Visualizer that brings algorithms to life using HTML, CSS, and JavaScript. Designed to help learners grasp the internal working of popular algorithms through engaging visual animations.

“Made with 💡 logic and ❤️ passion by Shivu — because algorithms deserve to be seen, not just studied.”

🚀 Features
📊 Visualize popular algorithms in real time:

Sorting: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort

Searching: Linear Search, Binary Search

(Optional) Pathfinding: Dijkstra’s Algorithm, A* Algorithm

🎮 Interactive controls: Play, Pause, Reset

🐢🦅 Adjustable speed and data size

🌙 Clean, responsive UI for light and dark themes

🚀 Getting Started
Clone this repository or download the ZIP.

Open index.html in any browser.

Select an algorithm, click visualize, and enjoy!
